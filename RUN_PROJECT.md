# Como executar o projeto full stack

## Backend
1. Entre na pasta backend
2. Execute: npm start

## Frontend
1. Entre na pasta frontend
2. Execute: npm run dev

## Endpoints principais
- http://localhost:3000/alunos
- http://localhost:3000/professores
- http://localhost:3000/turmas
- http://localhost:3000/avaliacoes
- http://localhost:3000/frequencias

## Observação
O backend cria automaticamente o arquivo SQLite em backend/src/database/escola.db.
