# Sistema-de-controle-acad-mico

# 📚 Sistema de Controle Escolar

## 📖 Sobre o projeto
O sistema tem como finalidade melhorar o acompanhamento das turmas escolares, permitindo um melhor controle de notas, frequência e desempenho dos alunos.

---

# 🚀 Funcionalidades
- Cadastro de alunos
- Cadastro de professores
- Gerenciamento de turmas
- Controle de frequência
- Sistema de avaliações
- Relatórios de desempenho

---

# 🧩 Classes do sistema

## 🧑‍🎓 Aluno
- nome
- matrícula
- turma
- idade

## 👨‍🏫 Professor
- nome
- disciplina
- email

## 🏫 Turma
- nome da turma
- ano letivo
- lista de alunos

## 📊 Avaliação
- tipo
- nota

## 📅 Frequência
- presenças
- faltas

---

# 🔗 Relações entre classes

- Professor ministra Turma (Associação)
- Turma possui Alunos (Agregação)
- Aluno possui Frequência (Composição)
- Aluno possui Avaliações (Composição)
